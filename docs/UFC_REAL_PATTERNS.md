# 真實 UFC 的比賽節奏與選手類型（設計戰鬥系統之前的底稿）

> 2026-11-09 Claude 整理，依使用者的描述加上一般 MMA 常識。**還沒經使用者確認**；數字都是概略，標「待查」的要核對。
> 目的：先搞清楚真實比賽長什麼樣，再決定遊戲機制。這份不談卡牌、不談數值。

## 1. 一場比賽的骨架

- 每回合 5 分鐘，一般 3 回合，主賽 5 回合。每回合獨立計分（10 分制，贏的一方 10 分），整場靠各回合累積。
- 判分看：有效打擊與有效抓摔、攻勢、控場（誰在決定打哪裡）。所以「搶先打到」「一直壓著」「控制時間」都有分，不一定要重傷對手。
- 結束方式：KO／TKO（含裁判或醫生叫停）、降伏、判定。判定大約占四到五成（待查）。
- 體力是整場的預算：每回合出招、摔、被摔、掙扎都在消耗。後面回合動作變慢、防守變鬆，是真實比賽常見的轉折。

## 2. 比賽會經過的幾個「場景」

| 場景 | 發生什麼 | 誰想要 |
|---|---|---|
| 站立遠距 | 試探、假動作、前手、低踢、步法找距離 | 打擊型 |
| 站立近距／抱纏 | 內圈拳、膝、貼籠抱纏、推人 | 看誰壓得住 |
| 抓摔 | 低身進攻、抱腿、絆摔、摔投；被防或被壓趴（sprawl） | 摔角型進、打擊型防 |
| 地面上位 | 控制、過腿、壓制、地面拳肘（GnP）、找降伏 | 摔角型、柔術型 |
| 地面下位 | 護腿防守、掃、找站起來（貼籠牆起身）、從下面鎖技 | 柔術型強，打擊型求脫身 |
| 裁判叫起 | 地面沒進展就讓雙方站起來重來 | — |

**核心矛盾：一場比賽真正在爭的，是「這場在哪一種場景裡打」。** 打擊型想一直在站立遠距，摔角型想進抓摔然後留在地面，柔術型連被壓在下面都不怕。其他的招式細節都是為了這個服務。

## 3. 一場比賽的時間弧線（使用者描述）

- **第 1 回合：試探。** 看距離、速度、反應、有沒有弱點。多數人不會全力衝，因為還要保留體力。
- **第 2 回合起：抓到節奏，朝弱點打。** 例如對手腿弱就狂踢腿、對手防摔差就開始摔、對手體力掉就加壓。
- **後段回合：體力與傷害累積決定走向。** 腿踢累積讓步法變慢、身體攻擊讓體力掉、頭部累積讓人變得容易被一擊倒。落後的人會冒險，領先的人會保守。
- **例外：爆衝型。** 像 Chimaev 這類人第一回合就直接爆摔，把「先爆發、壓死對手」當計畫；風險是自己體力消耗快。

## 4. 選手類型與他們的打法

### 4.1 站立打擊型
- 目標：一直站著打，三五回合內省體力，用距離和節奏贏。
- 流派：拳擊型（Poirier、Holloway 偏高頻率）、踢拳／泰拳型（Pereira）、空手道／反擊型（Adesanya、Thompson）、壓迫型。
- 進行方式：R1 試探，R2 起針對弱點（腿、身體、防守習慣）。防摔靠步法、壓趴、貼籠牆起身。
- 弱點：被摔、被壓在地面、被貼籠牆消耗。

### 4.2 摔角型
- 目標：把站立打擊型拖進地面，靠控制和地面拳肘贏判分，順便找降伏。
- 進行方式：先用站立試探與假動作掩護進攻，找對手的反應空檔再低身進。進了之後重點是「壓住不讓起來」。
- 流派：拳擊＋摔角混合（Cormier、Usman）、純粹壓制（Khabib 的籠邊壓制）、持續高壓抓摔（Merab）。
- 弱點：遠距離打擊、被打到後無法進攻、不斷抓摔會累。
- 例外：Chimaev 式 R1 直接爆摔。

### 4.3 柔術／降伏型
- 目標：不管上下位，只要進地面就有降伏機會；下位被壓也是機會（Oliveira 的下位三角鎖和背後控制）。
- 進行方式：可以拉guard（自己躺下）、可以靠摔角進入、也可以在站立搶機會。
- 弱點：站立若輸太多，在進地面前就被打倒；被強壓在籠牆下也很難施展。

### 4.4 全能／混合型
- 站立、抓摔、地面都不差，用「看對手弱點切換打法」贏（Jones、GSP、Volkanovski）。
- 特色：沒有明顯弱點，所以對手難以針對，但每一項都不一定比專精者強。

## 5. 對戰組合（誰想在哪裡打）

- **打擊 vs 打擊**：比距離、節奏、反擊；一拳可能定勝負；體力與腿傷、身體累積是中後段的轉折。
- **打擊 vs 摔角**：關鍵是「摔角型能不能近身並成功摔倒」與「打擊型能不能壓趴、起身、貼籠牆脫身」。摔倒之後打擊型往往只是求站起來。
- **摔角 vs 柔術**：摔角想上位壓制而不被鎖，柔術想讓比賽進到降伏的範圍。
- **柔術 vs 打擊**：柔術型需要靠近或拉guard；打擊型要避免被拖進地面，也不要被帶入。

## 6. 遊戲設計要不要抓住的重點（未決，待討論）

1. **回合弧線**：R1 試探 → R2 起針對弱點，需要「看穿對手」的機制（偵察、對手傾向），而不是每手重新開始。
2. **體力是預算**：三五回合內分配，強行爆發要付出代價。
3. **局部傷害累積**：頭（暈／被 KO）、身體（體力）、腿（機動），跟使用者說的「對方腳弱就打腳」直接對應。
4. **場景轉換才是戲肉**：站立 → 抱纏 → 摔／壓趴 → 地面 → 起身。誰決定場景，誰就占優。
5. **風格差異來自「想去哪個場景」**，不是來自數值大小。
6. **例外打法要存在**：爆衝 R1、拉guard、反擊型，不是所有人都照同一條弧線。
