## 2. 橫版版面（對戰頁）

以 iPhone 844×390pt 為設計基準，要適應安全區域與較小機型。

- **八角籠 `SpriteView` 滿版當背景**，不再因播放而改變尺寸；SwiftUI 介面疊在上面。
- **上方轉播列**：左右對稱的雙方血條（頭／身／腿＋體力、勢能）、中央回合數、回合進度與局勢。
- **下方手牌**：5 張扇形手牌，點選放大、往上拖＝出牌；播放交手時滑出畫面，人物與翻牌不被遮擋。
- **左下**：抽牌／棄牌數、上一手、戰報。**右下**：速度與選單（算式、重現碼、重開、回選角收進選單）。
- 畫面上要保留 Rocked／深鎖／流血警示。

人物顯示高度約 250pt 時，頭頂不會碰到約 38pt 高的轉播列，但腳可能接近手牌：站位要避開手牌，或在選牌時讓手牌只露出上半部。

## 3. 戰鬥人物：共用骨架＋官方照貼圖

### 3.1 為什麼是這個做法

原型比較過四種做法（三位選手：O'Malley、Adesanya、Pereira）：

| 做法 | 結果 |
|---|---|
| 照片身體壓成 Q 版 | 手臂切割瑕疵多，身體太窄 |
| 照片身體，頭身比約 30% | 辨識度好，但照片手臂一彎手肘就斷，動作受限 |
| 共用身體＋自動抽刺青 | 動作好，但抽取失真；深色皮膚的肌肉陰影會被誤判，或刺青幾乎消失 |
| **共用骨架＋照片貼圖（採用）** | 保留刺青位置與風格、膚色、肌肉陰影，防守／出拳／踢腿都做得到 |

### 3.2 官方照的限制（已實測）

- `athlete_bio_full_body` 為 460×700，**只拍到腰部或大腿**，沒有小腿和腳，手也常被裁掉。
- `event_results_athlete_headshot` 為 256×160。
- 只有正面照，看不到背部刺青。

### 3.3 部位來源與原型尺寸

| 部位 | 來源 | 原型尺寸（像素，寬×高） |
|---|---|---|
| 頭 | 大頭照，以下顎橢圓遮罩去掉脖子肩膀，縮放 0.40（約 45 高），獨立 24 色 | 依髮型而定 |
| 軀幹 | 全身照軀幹區域，當貼圖 | 44×38 |
| 上臂／前臂 | 全身照手臂區域，當貼圖 | 14×20／12×19 |
| 短褲 | 上緣用全身照下緣的花紋，下半部用模板＋本人配色 | 41×16 |
| 大腿／小腿／腳 | 共用素材，染成本人膚色 | 16×20／13×19／約 15×4 |
| 手套 | 共用素材 | 11×11 |

- 軀幹與手臂共用一組 28 色色盤，讓各部位顏色一致；貼圖透明處先以膚色補滿。
- 膚色取自軀幹照片，排除刺青像素後取中位數，再產生陰影（×0.72）與高光（×1.12）。
- 原型實際頭身比為 36–38%；目標約 35%，以「臉仍認得出來」為優先。

### 3.4 骨架與姿勢

每個四肢是掛在關節上的圓角貼圖，以關節旋轉；放大顯示時用最近鄰取樣。原型角度如下（0 = 自然下垂，正值朝 +x 擺動）：

| 姿勢 | 上臂 左／右 | 前臂 左／右 | 大腿 左／右 | 小腿 左／右 |
|---|---|---|---|---|
| 防守 | −38／38 | 176／−176 | −12／14 | −4／4 |
| 出拳 | −38／82 | 176／88 | −16／18 | −6／6 |
| 踢腿 | −42／42 | 172／−172 | −4／82 | −2／70 |

### 3.5 已知未解

1. **自動切割未驗證**：原型的切割框是手動量的。Vision 能否跑完所有選手是最大風險（P6-2）。
2. **體型相同**：骨架寬度三人相同，需要 2–3 種體型。
3. **質感不一致**：照片軀幹和程式畫的腿落差明顯，正式腿素材要配合。
4. **朝向**：人物基本是正面，不是側身格鬥站姿。使用者看過原型後已接受此取捨。
5. **地面戰**：舊規劃的雙人姿勢模板如何搭配此骨架，尚未設計。實作前先維持現有地面呈現。

### 3.6 退路

某位選手切割失敗或無官方照時，戰鬥中退回現有 `body_116` 整張像素圖（無四肢動作）；無照片者維持量級剪影（`RULES.md` §4.2）。

## 4. 原型重現方式

原型腳本在 `pipeline/prototypes/`（只有程式，沒有照片），依賴鏈為 `shared35.py` → `shared_body.py` → `chibi3.py`。

1. 建一個**不在 repo 內**的工作資料夾 `<ROOT>`，內含 `tools/`、`photos/`、`out/`，並把三個腳本複製到 `tools/`。
2. 依 `data/fighters.json` 的網址，把 Sean O'Malley、Israel Adesanya、Alex Pereira 的照片下載為 `photos/{omalley,adesanya,pereira}_{body,head}.png`。
3. 在 `<ROOT>` 外執行（只支援 Windows，標籤字型路徑寫死）：

```bash
uv run --no-project --with pillow --with httpx --with numpy python -W ignore -I "<ROOT>/tools/shared35.py" "<ROOT>" "<repo 路徑>"
```

輸出在 `<ROOT>/out/`：`shared35_comparison.png`（比較圖）與 `shared35_stage.png`（橫版示意）。**輸出含官方照衍生圖，不可 commit。**
