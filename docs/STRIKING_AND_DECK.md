# 🥊 站立打擊系統規格 (Striking & Deck)

> 站立是 10 分鐘對局裡佔比最高的部分（約 60–70% 的交手）。設計目標：**每次出牌都有「讀心」，但不靠純運氣；位置、距離、傷害累積都會改變下一手的選擇。**
> 地面請見 [GROUND_GAME_DESIGN.md](GROUND_GAME_DESIGN.md)，戰力公式請見 [POWER_SYSTEM.md](POWER_SYSTEM.md)。

---

## 1. 站立的 4 個狀態軸

| 軸 | 值 | 作用 |
|---|---|---|
| 📏 **距離 Range** | 遠 Long / 中 Mid / 近 Close | 每張卡有適用距離，距離不對 → 命中大減 |
| 🧭 **籠中位置 Cage** | 中央 / 靠籠 / 被逼角落 | 影響可用移動卡；壓制方有籠邊專屬卡 |
| 🦶 **站姿角度 Angle** | 正對 / 外側 / 內側 | 由站姿（正手 vs 左撇子）與走位決定，影響直拳/高踢的命中 |
| 🧠 **姿態 State** | 正常 / 被打暈 Rocked / 追擊 Swarm | Rocked：防守選項受限；Swarm：打暈對手後的追擊窗口 |

> 距離是核心：打擊手想**保持中遠距離**，摔角手想**縮到近距離**，每一次「移動卡」都是在爭奪這個軸。

## 2. 卡牌的 6 大類型（讀心的基礎）

| 類型 | 代表 | 本質 |
|---|---|---|
| 🗡️ **進攻 Strike** | 刺拳、直拳、鉤拳、各種踢、膝、肘 | 造成傷害、消耗體力 |
| 🛡️ **格擋 Block** | 抱頭、肘擋、擋踢 | 吸收大部分傷害，但仍有少量穿透 |
| 💨 **閃避 Evade** | 後仰、側閃、滑步 | 完全躲開，但吃體力與位置 |
| ↩️ **反擊 Counter** | 反擊鉤拳、接踢反摔、抓踢 | 對手出手瞬間觸發，成功傷害 ×2 |
| 🎭 **佯攻 Feint** | 假動作、虛晃摔 | 本身不傷害；成功則對手**讀心錯誤**，下一手被你牽制 |
| 🏃 **移動 Move** | 前進逼近、側移、後撤、轉向 | 改變距離／位置／角度 |

### 2.1 同時出牌的「機率優勢表」（不是剪刀石頭布）

> 原則：**沒有任何組合是必勝或必敗**。表中數字是「**基準成功機率**」，再套用屬性、特性、體力、氣勢、距離、讀心修正；最終機率被限制在 **5%–95%** 之間，永遠有冷門。
> 「相剋」只代表**機率偏高或偏低**，而且幅度溫和（多數落在 30%–65%）。

**橫列 = 我出的牌，直欄 = 對手出的牌，數字 = 我這張牌「達成預期效果」的基準機率**

| 我出的牌（預期效果） | 對手：進攻 | 對手：格擋 | 對手：閃避 | 對手：反擊 | 對手：佯攻 | 對手：移動 |
|---|---|---|---|---|---|---|
| 🗡️ **進攻**（命中造成傷害） | 55% 互換，比速度 | 35% 打穿 | 30% | 40% | 65% | 55% |
| 🛡️ **格擋**（吸收傷害） | 65% | — | — | — | 35% 被騙 | — |
| 💨 **閃避**（完全躲開） | 55% | — | — | — | 40% 被騙 | — |
| ↩️ **反擊**（反擊成功 ×2） | 60% | 10% | 10% | 10% | 15% 被騙 | 10% |
| 🎭 **佯攻**（讓對手破功） | 25% 被打斷 | 55% | 50% | 65% | 30% | 40% |
| 🏃 **移動**（取得距離/位置優勢） | 45% | 55% | 55% | 55% | 50% | 50% 位置爭奪 |

### 2.1.1 最終機率怎麼算（公式定案，供 P2-2 實作）

`最終機率 = Odds.resolve(base: 基準機率, modifiers: [屬性差, 距離修正, 體力修正, 氣勢修正, 特性修正, 讀心加成])`（強制夾在 **5%–95%**）

1. **基準機率 (`base`)**：查 §2.1 的 6×6 矩陣。
   - 表中標註 `—` 的格子（格擋/閃避 對上 格擋/閃避/反擊/移動）：雙方都未發動實質進攻或破防，該手「無交鋒（No Contact）」，但為讓 `resolveOdds` 對任意組合皆有定義，表內填 **基準值 `0.50`**（代表維持原姿態/不失位）。
2. **屬性差修正 (`attributeModifier`)**：每 1 點差距 = `0.002`（即相差 50 點 = `±10%`）：
   - 我出 **進攻 Strike**：`((my.accuracy + card.accuracy) / 2 - opp.strikingDefense) * 0.002`
   - 我出 **格擋 Block / 閃避 Evade**：`(my.strikingDefense - (opp.accuracy + oppCard.accuracy) / 2) * 0.002`
   - 我出 **反擊 Counter**：`((my.accuracy + my.speed) / 2 - opp.speed) * 0.002`
   - 我出 **佯攻 Feint**：`(my.accuracy - opp.strikingDefense) * 0.002`
   - 我出 **移動 Move**：`(my.speed - opp.speed) * 0.002`
3. **距離修正 (`distanceModifier`)**：
   - 若當前 `state.distance` 在 `myCard.distances` 內：`0.0`
   - 若相差 1 格（例：適用中距離，當前為遠或近）：`-0.20`（-20%）
   - 若相差 2 格（例：適用遠距離，當前為近距離）：`-0.35`（-35%）
4. **體力與傷病修正 (`conditionModifier`)**：
   - 體力低於 `40` 時：每少 1 點體力 `-0.003`（體力 0 時 `-12%`）
   - 腿部血量低於 `50` 時：出 `move`、`evade` 或含 `.kick` 標籤的卡 `-0.10`（-10%）
5. **氣勢修正 (`momentumModifier`)**：
   - `(myCondition.momentum - oppCondition.momentum) * 0.0005`（差距 100 時 `±5%`）
6. **特性修正 (`traitModifier`)**：
   - 我有 `.counterPuncher` 且出 `.counter`：`+0.08`
   - 我有 `.onePunch` 且出 `.strike`（power ≥ 75）：命中 `-0.05`（但傷害與 KO 率在結算時加成）
   - 對手有 `.unorthodox` 且我出 `.counter` 或 `.feint`：`-0.06`
7. **讀心加成 (`readModifier`)**：
   - 若對手連續重複同一類型卡牌，每次約 `+0.03`，上限 `+0.10`（P2-2 可先預留參數預設 `0.0`）。

### 2.1.2 為什麼用機率
1. 真實比賽裡「相剋」只是傾向：反擊手會被打中，佯攻也可能被看穿。
2. 冷門才有戲劇性：低機率成功時，爽感更高。
3. 平衡好調：只要改數字，不用改規則；之後由**回測引擎**用真實勝負反推調整。

> 上表為**第一版起始值**，不是定案；之後由模擬器跑上萬場，檢查是否有「全閃避」「全反擊」這種過強單一策略並調整。

## 3. 卡牌結構（Card Anatomy）

每張卡的欄位：

| 欄位 | 說明 | 例：高踢 Head Kick |
|---|---|---|
| 名稱／類型 | 六大類之一 | 進攻 |
| 適用距離 | 遠/中/近 | 中–遠 |
| 目標 | 頭 / 身 / 腿 | 頭 |
| 速度 Speed | 同時互打時誰先到 | 慢 |
| 威力 Power | 基礎傷害 | 高 |
| 精準 Accuracy | 基礎命中 | 低 |
| 體力 Cost | 消耗 | 4 |
| 牌組點數 Deck Cost | 構築預算 | 3 |
| 標籤 Tags | 拳/腿/肘/膝/摔/鎖… | 腿、踢 |
| 風險 Risk | 失敗後果 | 落空 → 被反摔機率↑ |
| 特殊效果 | 條件式 | 命中且對手 Rocked → 直接進 Swarm |

| 距離 | 進攻 | 防守／其他 |

| **中** | 直拳、鉤拳、上鉤拳、過肩拳、旋身肘、膝、組合拳起手 | 格擋、側閃、反擊鉤拳、佯攻 |
| **近** | 肘擊、貼身膝、肘膝連段、髒拳 Dirty Boxing | 頭部控制、纏抱掙脫、抱摔 |

## 4. 傷害模型（打哪裡，有不同的長期後果）

三條部位血量，各自觸發不同後果：

| 部位 | 累積傷害的後果 | 終結條件 |
|---|---|---|
| 🧠 **頭** | 傷害累積 → 下巴/抗打檢定越來越危險；進入 **Rocked** | 頭血歸零 → **KO/TKO**（也可閃擊 KO，見下） |
| 🫁 **身體** | 體力恢復變慢、最大體力下降；「肝臟重擊」特例 | 單發重擊有小機率直接癱倒（肝擊 KO，**需低體力**才觸發） |
| 🦵 **腿** | 移動卡命中↓、踢擊威力↓、防摔能力↓ | 腿血歸零 → 無法站穩（TKO 或被摔無法起身） |

### 4.1 Rocked（被打暈）與 Swarm（追擊）
1. 重擊命中，且對手頭血低於某門檻或抗打檢定失敗 → 對手進入 **Rocked**
2. Rocked 下：對手**只能選 格擋 / 抱住 / 移動**，無法進攻
3. 你進入 **Swarm**：可打出 **2–3 張連打**，每張命中累積 KO 風險
4. 對手可用 **抱住（纏抱）** 保命：成功 → 轉為纏抱位置；失敗 → 繼續被打
→ 這是 10 分鐘對局中最大的「戲劇點」，每局應有 1–3 次。

### 4.2 閃擊 Flash KO
- 重擊命中且「頭血偏低 + 抗打差」→ 小機率直接 KO，**絕不是 0%，也不是必殺**
- 一擊必殺特性：機率 ×1.3；鐵下巴：×0.6

## 5. 連段 Combo 與體力

- 每次交手可選 **單張**，或在**體力足夠**時串 **2–3 張連段**
- **連段規則**：
  1. 第一張命中，後續張數才會結算；第一張落空 → 連段中止，你吃更大的反擊懲罰
  2. 對手的「反擊」可在任何一張被中斷
  3. 特定序列有 **Combo 加成**（刺拳→直拳→鉤拳、低掃→高踢 = 對手防守 −）
- **體力 Stamina**：
  - 每張卡扣體力；體力低 → 命中/威力/速度全面打折
  - 每回合結束恢復一部分，受 Cardio 與身體傷影響
  - **「喘氣」不是特例，而是整局節奏**：衝太快 → 第 3 回合沒油

## 6. 氣勢 Momentum 與招牌技

- 氣勢來源：打中、閃過重擊、成功反擊、成功摔；被打、落空、被摔會下降
- 氣勢滿 → 可使用 **招牌卡 Signature**（每人 1–2 張，依真實勝法生成）
- 招牌卡特徵：威力極大、有專屬演出（本人大頭切入）、**可被讀心反制**
- 氣勢也影響**裁判計分**（見下）：表現強勢的回合更容易被判 10-9 / 10-8

---

## 7. 籠邊 Cage 與纏抱 Clinch

### 7.1 籠邊
- 靠籠方：「移動」卡選項減少、被摔機率↑
- 壓制方：獲得專屬卡（**籠邊頂住、貼身膝、肘擊**），可改變成**纏抱**
- 被逼角落者可用「轉身脫離 Pivot」，成功率受速度 / 摔角防禦影響

### 7.2 纏抱
- 站立與地面的過渡層：可打 **膝、肘、頭部控制、絆摔 Trip、抱摔、鎖（斷頭台）**
- 纏抱不是終點：每次交手後，雙方選擇 **分開 / 繼續纏 / 轉摔**；若連續 3 次消極（Stall），**裁判分開**

---

## 8. 抱摔（站立→地面的橋）

1. 進攻方選 `摔` 類型卡（雙腿、單腿、過肩、絆摔、籠邊抱摔）
2. 防守方選 `防摔 Sprawl` / `反擊` / `閃避`
3. 結算：進攻方 TD 屬性 vs 防守方 TD Defense；**距離**（近距離大加成）；**腿傷**（腿傷重 → 防摔差）
4. 成功 → 進入地面，依摔法決定**起始位置**（雙腿→全防守/半防守、籠邊絆摔→半防守、反摔→更高位置）
5. 失敗 → 進攻方被 sprawl 壓住或被反擊，**損失體力與位置**

## 9. 裁判計分（每回合結算）

| 指標 | 權重（預設） |
|---|---|
| 有效打擊與傷害 | 40% |
| 地面／纏抱控制與有效降伏威脅 | 25% |
| 進攻積極性與主導性 | 20% |
| 防守與位置 | 15% |

- **每回合計 10-9**；壓倒性（大量傷害 / 多次 Rocked / 近降伏）→ **10-8**；極少見平手 10-10
- **三位裁判各有偏好**：A 偏重打擊，B 偏重控制，C 平衡；各自微小雜訊 → 可能出現**分歧判定**
- 玩家可選：回合間顯示「**預估計分**」（休閒），或隱藏（硬派）

## 10. 站立 AI（對手怎麼出牌）

| 層 | 機制 |
|---|---|
| **風格傾向** | 由真實數據：出手量 → 進攻率；防摔 → 防摔反應；TD 平均 → 摔技率；反擊型 → 閃避/反擊比例 |
| **情境調整** | 體力低 → 保守；被打暈 → 抱住；領先 → 保守；落後最後回合 → 冒險 |
| **學習** | 偵測你重複的出牌 → 預判率上升（可關閉） |
| **性格** | 勇猛／計算／情緒（被激怒會變得輕率） |
| **難度** | 影響「讀心率」上限與失誤率，**不作弊加屬性** |

## 11. 牌組與抽牌規則

- **牌組 20 張**，每張有 **牌組點數**，總預算由選手屬性決定（避免全塞大招）
- 同名卡最多 3 張；至少含：打擊 ≥ 6、防守/閃避 ≥ 4、移動 ≥ 3
- **每人出廠預設牌組**（自動由風格生成），進階玩家可自行構築
- 每回合手牌 5 張，出完補牌；**賽前戰術滑桿**影響抽牌權重（例：偏摔角 → 抽到摔技卡機率高）
- **卡牌熟練度**：用得越多，該卡命中/威力微幅上升（生涯系統）

## 12. 一次交手的完整流程（從頭到尾）

1. 顯示狀態：距離、位置、體力、血量、Rocked 與否
2. 雙方各選 **1 張**（或連段）→ **蓋牌**
3. 同時翻開 → 依相剋矩陣與速度決定先後
4. 結算命中、傷害、體力、位置、氣勢、Rocked
5. 演出（L0/L1 動畫）
6. 補牌、檢查終結條件（KO/降伏/倒地/時間）
7. 每 8 次交手結束一回合 → 角落時間與計分
