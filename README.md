# Octagon Cards

Personal turn-based card fighting + career game driven by real UFC data (iOS, native Swift, pixel art).
Self-use only. Design docs live in [`docs/`](docs/), project rules in [`RULES.md`](RULES.md).

## Layout
- `Packages/OctagonCore` pure-Swift engine (no UIKit/SpriteKit), tested in CI
- `App/` SwiftUI + SpriteKit app, project generated by XcodeGen from `project.yml`
- `.github/workflows` free macOS CI and unsigned IPA build (tag `v*` or manual run)

## Build an IPA (free)
1. Tag and push: `git tag v0.0.1 && git push origin v0.0.1` (or run the workflow manually)
2. Download the `OctagonCards-unsigned-ipa` artifact: `gh run download <run-id>`
3. Sign and install with FlareStore on the iPhone. Signing files never go in this repo.
