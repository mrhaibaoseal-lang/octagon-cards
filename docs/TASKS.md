## M1 戰鬥擴充計畫（2026-11-07 使用者同意方向，尚未實作）
> 保留同時出牌、三角相剋、能量投入、一手只擲一次骰。真實度放在招式名稱、距離、位置和鎖技條件。實作時才改 `docs/GAME_DESIGN.md`；數值都是初估，模擬門檻要重驗，AI 和模擬器要跟著改。

### M1.1 距離、移動、站立牌、流血
- **距離軌**：取代「距離不對只打折」。雙方共用一條四格軌道，畫面常駐顯示：遠距、中距、近距、纏抱。每張牌標可用距離，不符合就變灰不能出；有些牌可跨兩格（例：刺拳可用於中距、近距）。遠距不能直接抱摔。
  | 距離 | 招式舉例 |
  |---|---|
  | 遠距 | 前踢、高踢、卡夫踢 |
  | 中距 | 刺拳、直拳、過肩重拳、掃踢、抱腿 |
  | 近距 | 鉤拳、上鉤拳、肘擊、雙腿摔 |
  | 纏抱 | 箍頸膝撞、貼身肘、絆摔、高跨重摔 |
- **移動牌**：納入三角相剋，不另立規則。
  | 牌 | 牌型 | 效果 |
  |---|---|---|
  | 前進一步（基本，永遠可出） | 摔抱 | 靠近 1 格 |
  | 後退一步（基本，永遠可出） | 防反 | 拉開 1 格 |
  | 大步衝入 | 摔抱 | 靠近 2 格，耗能較多 |
  | 壓步刺拳 | 打擊 | 邊打邊進 |
  | 後撤反拳 | 防反 | 邊打邊退 |
  | 側閃繞出 | 防反 | 拉開距離並閃過重擊 |
- **連段跨距離**：牌依序檢查距離，第一張改變距離後，第二張用新距離判定（例：壓步刺拳 + 鉤拳）。出牌畫面要能決定順序。
- **揮空**：對轟時投入少的先到；先到的牌把距離拉開，對手那張牌就打空。
- **防卡手與防逃跑**：基本步法永遠可出；手牌保底改成考慮目前距離。純移動不得分，一路後退會輸給前進。
- **站立牌擴充**：新增超人拳、飛膝、轉身後踢、組合拳、假動作、推籠、斷頭台（防反牌，抓對手摔得不好時）等。每人站立牌約 14–16 張，若四格距離常抽不到能用的牌再調。
- **流血（參考原版，數值重訂）**：
  - 割開不另外擲骰：肘擊命中頭部就割開；其他頭部攻擊要爆擊才割開；地面肘擊也算。
  - Lv1 影響裁判評分；Lv2 血流進眼睛，對手傾向只看得到最可能的牌型；Lv3 頭部再被爆擊，醫生叫停（TKO）。
  - 角落「止血消腫」降 1 級，要和回體力取捨。
  - 畫面先用血滴特效和流血標記，不增加生圖。
- **畫面**：移動先用現有姿勢滑動呈現，使用者看過再決定夠不夠。

### M1.2 地面系統
- **地面獨立牌組**：取代「牌不分站立或地面」。被摔倒後手牌換成地面牌，每人約 8 張。三角相剋和能量規則不變，高踢不會再變成砸拳。
  | | 打擊 | 摔抱 | 防反 |
  |---|---|---|---|
  | 上位 | 短砸拳、肘擊、騎乘連打 | 過半防守、過側控、上騎乘、取背、各種鎖技 | 穩壓、壓肩消耗、解三角絞 |
  | 下位 | 上踢、下位肘 | 蝦行拉回防守、橋翻、掃翻、貼籠起身 | 三角絞、十字固、木村鎖、膝盾 |
- **五段位置**：全防守 → 半防守 → 側控 → 騎乘或背後，另有貼籠起身。好的摔法可直接落在較好的位置，否則 15 手內走不完。
- **鎖技看位置**：例如裸絞只能在背後，十字固要騎乘或下位，三角絞只能在下位；被騎乘時能用的牌很少，全防守下位還能反擊。
- **牌組規模**：兩階段完成後，一般牌從 30 張增加到約 60 張以上，新增的牌主要拉開選手差異（Khabib 控制與砸拳，Oliveira 鎖技與下位陷阱）。
- **美術限制**：先用現有暫代姿勢驗證玩法。地面姿勢每人多約一批（PixelLab 骨架約 3 次），300 人約多 900 次，好玩之後再決定怎麼出圖。
