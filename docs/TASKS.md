## M1.4 規格
> 實作時才改 `docs/GAME_DESIGN.md`；數值都是初估，模擬門檻要重驗，AI 和模擬器要跟著改。

> **原因**：原本站立「打擊＞摔抱＞防反」三角相剋、地面「4 猜 1」與鎖技「3 猜 1」本質仍是剪刀石頭布，決策被「看機率條猜顏色」綁架，缺乏格鬥立回與連段拆招樂趣。
> **核心方向**：參考《Yomi》（速度×高低段位）、《將軍對決 Shogun Showdown》（三拍時間軸）、《殺戮尖塔》（半明牌起手拆招）與真實巴西柔術（重心×部位控制支點），保留四格距離軌、五段地面位置、15 位選手能力、流血與傷勢。
> **與使用者確認的三點**：① **一次排完 3 拍再連續開打**（看對手 3 拍起手預告 → 排好自己的 1～3 拍連段 → 按開打看 3 拍連續過招動畫）；② **慢招清楚預告段位、快招半明牌**（2 拍重招直接顯示「蓄力→上/下段重擊」讓玩家拆招，1 拍快招只提示「快攻/步法」，靠看穿能力才露牌名）；③ **鎖技直接整合進地面時間軸與部位控制**（上鎖後不切另一套猜拳按鈕或計時條，直接用手牌搶手腕/重心來加深或拆解鎖技）。

- **站立：三拍時間軸（Beat 1 → Beat 2 → Beat 3）**
  - 每手固定 **3 拍槽位**（回合最後一手或氣勢爆發可解鎖第 4 拍；體力過低時第 3 拍鎖定為喘息）。未排牌的空拍自動視為「回氣架勢」（回少量體力、輕微減傷）。
  - **1 拍牌（快招／步法／輕防）**：刺拳、卡夫踢、前踢、內圍短拳、貼身肘、前進／後退、高抱架、後仰閃避、提膝擋踢、下潛防摔（Sprawl）。當拍結算。
  - **2 拍牌（重擊／大摔／大反擊）**：直拳、左直拳、過肩重拳、上鉤拳、高踢、轉身後踢、雙腿摔、籠邊絆摔、高跨重摔、轉身重擊。佔連續 2 拍：**第 1 拍為「起手／蓄力／下潛」（無傷害，可被打斷或拉開），第 2 拍為「命中結算」**。
- **半明牌預告（對手起手徵兆 Tell）**
  - 每手開始時 AI 先排好 3 拍序列，畫面上方時間軸顯示對手每一拍的徵兆：
    - **2 拍重招**：起手動作大，直接顯示 `拍N [⚠️蓄力/下潛] → 拍N+1 [💥上段重擊 / 🤼下段抱摔（標明射程）]`。
    - **1 拍快招**：起手快，只顯示 `拍N [⚡快攻]`、`[👣步法移動]` 或 `[🛡️防守架勢]`。
    - **看穿與流血 Lv2**：「看穿」標記直接翻開對手 3 拍的真實牌名；流血 Lv2（血流進眼）則把對手的預告遮蔽成 `[❓視線模糊]`。
- **逐拍結算（廢除 S/G/C 相剋，每拍依序檢查三件事）**
  1. **位移與距離揮空（Whiff）**：步法先更新四格距離軌（遠／中／近／纏抱）。當拍出手的攻擊若不在有效射程內，直接 **揮空（Whiff）**（0 傷害、多耗體力，並掛上 1 拍 **`[破綻]`**：下一拍挨打必爆擊且無法防禦）。
  2. **出招速度（Speed 1–10）與蓄力打斷（Interrupt）**：
     - 雙方都在射程內出手時，**速度快者先命中**（刺拳 `速9` ＞ 鉤拳 `速6` ＞ 重拳 `速3`）。快招先中若未打暈或擊退對手，慢招隨後也會打回來（真實換血）。
     - **打斷大招**：當對手處於 2 拍招的「第 1 拍蓄力／下潛」時，若被你的 **截擊技**（迎擊刺拳、前踢、箍頸膝撞）命中或被打暈／推開射程，他第 2 拍的大招直接 **被打斷取消**！
  3. **高低段位攻防（High / Mid / Low Mix-up）**：
     - 攻擊分 **上段（頭：拳、肘、高踢）**、**中段（身：腹拳、前踢、掃踢、膝撞）**、**下段（腿／摔：卡夫踢、單雙腿抱摔）**。
     - 防守牌對應段位：
       - **高段防反（高抱架、後仰閃拳、滑步後撤）**：完美化解 **上段**（免傷＋反擊或令對手露 `[破綻]`），對 **中段** 減傷 50%，但被 **下段（抱摔／低掃）** 直接破防！
       - **下段防反（下潛防摔 Sprawl、提膝擋踢、斷頭台）**：完美潰擊 **下段**（擋踢反傷腿部；Sprawl 潰擊抱摔扣對手大量體力並可反壓進上位；斷頭台直接抓下潛進鎖技），對 **中段** 減傷 50%，但被 **上段（高踢／上鉤拳）** 直接破防爆頭！
     - **高低配鋪路**：下段命中掛上 `［防線下移］`（高防失效、上段加爆擊）；上段連中掛上 `［視線受阻］`（防摔下降、下段抱摔加成）。
- **地面與鎖技：重心（Posture）× 三大控制支點（手腕／頸部／髖部）**
  - 保留 **五段位置軌（全防守 → 半防守 → 側控 → 騎乘 → 背後）**，廢除地面 4 猜 1 與鎖技 3 猜 1，**地面同樣用 3 拍時間軸（看對手半明牌預告 → 排 3 拍 → 逐拍結算）**。
  - **地面核心狀態**：
    - **重心（Posture）**：`-1［壓低緊貼］` ↔ `0［平穩］` ↔ `+1［挺身拉開］`。
    - **三大控制支點（Grips）**：**`[手腕]`**、**`[頸部]`**、**`[髖部]`**（雙方爭奪支點控制權）。
  - **上位（Top）三路線**：
    - **砸拳（GnP）**：需先「挺身拉開（`+1`）」才能揮出重砸拳／重肘（傷害 ×1.5），但挺身會放開 `[髖部]`，給下位逃脫空檔；在 `壓低（-1）` 時只能出輕短拳。
    - **過位（Pass）**：需先取得 **`[髖部]`** 控制並壓低重心，下一拍出過位牌即可推進一段位置。
    - **上位鎖技**：在對應位置取得 **`[手腕]`**（木村鎖、十字固、美式鎖）或 **`[頸部]`**（肩固、裸絞），即可打出鎖技牌掛上鎖定！
  - **下位（Bottom）三路線**：
    - **拉頸崩重心**：把上位從 `+1［挺身］` 拉回 `-1［緊貼］`，直接廢掉他下一拍預告的重砸拳。
    - **撐架逃脫／翻身**：搶下 **`[髖部]`** 控制（撐架推髖、蝦行）後，下一拍退回前一段位置（全防守退一段即站起）；趁上位重心不穩打出「蝴蝶鉤／橋翻」直接上下位互換。
    - **下位鎖技**：搶下 **`[手腕]`** ＋ **`[頸部]`**（或趁對手 `-1［緊貼］`），直接打出三角絞、下位十字固或斷頭台！
  - **鎖技深度整合（1/3 → 2/3 → 3/3 拍墊，不切獨立小遊戲）**：
    - 鎖技掛上後，在地面時間軸上直接顯示 **「鎖技深度（1/3 ～ 3/3）」**。
    - 進攻方用後續拍子打出「收緊／壓頭／轉角」推進深度（滿 3/3 拍墊降伏）；防守方看預告打出對應支點的拆解牌（「雙手護腕」、「堆疊壓重」、「轉身抽手」）搶回支點，把深度降回 0 即可掙脫。
